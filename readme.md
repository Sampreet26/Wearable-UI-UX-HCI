How to Run the Project



1\. Install Requirements



* Install Android Studio on your system.
* Make sure the Android Emulator or a physical Android device is available.
* Open the project folder in Android Studio.



2\. Open the Project



* Start Android Studio.
* Choose "Open an existing project".
* Select the folder where this project is located.
* Wait for Gradle to download and finish syncing.



3\. Run the App



* Connect an Android device or start an emulator from Android Studio.
* Click the green "Run" button in the toolbar.
* The app will build and install on your device.



4\. Features Available



* Glanceable dashboard showing steps, heart rate, and movement minutes.
* Haptic feedback alerts
* Voice commands using Android speech recognizer
* Simple and clean UI designed using Jetpack Compose
